# qa-saucedemo-project
This is a non-commercial QA portfolio project where I practice manual UI testing on SauceDemo and demonstrate API testing and SQL skills; Documentation is maintained in English; a Russian version can be prepared upon request.
Документация проекта ведётся на английском языке, чтобы портфолио было универсальным и подходило для международных вакансий. При этом я свободно владею русским языком и при необходимости могу подготовить русскую версию материалов (тест-план, тест-кейсы, чек-листы, баг-репорты и т.д.).
